# 随剧听（ST-Music）

SillyTavern 的音乐播放扩展。

## 当前功能（0.3.0）

- 悬浮按钮：点击打开播放面板，可拖动；大小和内容可在设置中调整。
- 播放面板：卡片或全屏。卡片可拖动顶部移动、按住四角调整大小；双击顶部横杠在两种形式间切换。
- 搜索网易云歌曲并播放；播放列表从面板底部弹出。
- 歌词：点击唱片切换；拖动时出现中线，点击中线跳到该句；有平台译文的歌曲可显示译文。
- 歌词长条：只显示当前一句的小窗，可拖动，关闭面板后显示。
- 收藏、最近播放、播放排行、歌单；可从网易云歌单链接或文本清单导入歌单。数据仅保存在本地。
- 按剧情选歌：模型在回复末尾输出隐藏标签，插件据此检索歌曲并排到当前歌曲之后。
- 后台播放：向系统登记媒体信息；可开启后台保活。
- 动效风格三种；界面颜色跟随酒馆当前主题。

## 按剧情选歌的说明

- 开启后，到了推荐间隔的那一条回复会在提示词里多一段说明，AI 的回复末尾多输出几十个字；其余回复不受影响。不额外调用 AI。
- 标签读取后会从消息正文里删除，不占用后续上下文。
- 默认开启，可在扩展设置的「按剧情选歌」里关闭。

## 安装

在酒馆的「扩展」→「安装扩展」中填入本仓库地址：

```
https://github.com/Mshiyuan/ST-Music
```

## 说明

- 歌曲数据来自公共接口，只能播放平台允许免费播放的歌曲；无法播放的歌曲会提示并自动跳到下一首。
- 公共接口可能失效。扩展设置里可以开关各个接口，或填写自定义的 Meting 格式接口地址。
