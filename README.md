# ST-Music

SillyTavern 的音乐播放扩展。

## 当前功能（0.2.0）

- 悬浮按钮：点击打开播放面板，可拖动到任意位置；大小和内容（图标、当前封面、自定义图片、自定义文字）可在设置里调整。
- 播放面板：卡片或底部抽屉两种形式。卡片可按住顶部拖动、按住四角改大小。
- 左上角放大镜搜索网易云歌曲；右下角列表图标打开播放列表，列表从面板底部弹出。
- 播放、暂停、上一首、下一首，列表循环 / 单曲循环 / 随机。
- 点击唱片切换到歌词，歌词随播放滚动。上下拖动歌词时中间出现一条线，显示该句的时间，点这条线跳到该句；点其他地方回到唱片。
- 歌词页左下角的「译」开关平台自带的中文译文；没有译文的歌该按钮不可用。
- 按剧情选歌：AI 在回复末尾附一个不显示的标签，插件据此搜歌并排到当前歌曲之后。可设置推荐间隔、每次几首、语言偏好、不要的版本。播放列表右上角的按钮可用同一组标签换一批，不调用 AI。
- 动效风格三种：弹簧阻尼、平滑、淡入淡出。
- 界面颜色跟随酒馆当前主题。

## 按剧情选歌的说明

- 开启后，到了推荐间隔的那一条回复会在提示词里多一段说明，AI 的回复末尾多输出几十个字；其余回复不受影响。不额外调用 AI。
- 标签读取后会从消息正文里删除，不占用后续上下文。
- 默认开启，可在扩展设置的「按剧情选歌」里关闭。

## 安装

在酒馆的「扩展」→「安装扩展」中填入本仓库地址：

```
https://github.com/Mshiyuan/ST-Music
```

## 说明

- 歌曲数据来自公共接口，只能播放平台允许免费播放的歌曲；无法播放的歌曲会提示并自动跳到下一首。
- 公共接口可能失效。扩展设置里可以开关各个接口，或填写自定义的 Meting 格式接口地址。
