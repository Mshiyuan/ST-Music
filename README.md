# ST-Music

SillyTavern 的音乐播放扩展。

## 当前功能（0.1.0）

- 悬浮按钮：点击打开播放面板，可拖动到任意位置。
- 播放面板：卡片或底部抽屉两种形式。卡片可按住标题栏拖动、拖四角改大小。
- 搜索网易云歌曲，播放、暂停、上一首、下一首，列表循环 / 单曲循环 / 随机。
- 点击唱片切换到歌词，歌词随播放滚动，可上下拖动查看；再点一下回到唱片。
- 界面颜色跟随酒馆当前主题。

## 安装

在酒馆的「扩展」→「安装扩展」中填入本仓库地址：

```
https://github.com/Mshiyuan/ST-Music
```

## 说明

- 歌曲数据来自公共接口，只能播放平台允许免费播放的歌曲；无法播放的歌曲会提示并自动跳到下一首。
- 公共接口可能失效。扩展设置里可以开关各个接口，或填写自定义的 Meting 格式接口地址。
